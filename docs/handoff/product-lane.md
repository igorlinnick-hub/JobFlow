## Грабли захода (чтобы не наступать заново)

- Тест, зависящий от окружения (`.env` без/с ключами) — форсить состояние патчем (#143).
- Мок-тесты не ловят SDK-классы багов — денежный путь гонять РЕАЛЬНЫМИ SDK-объектами.
- `ruff format` на КАЖДЫЙ тронутый файл (провал #146 → красный main → #151).
- Ext-релоад программно: `HIREDROP_SET_FLAG hd_debug` → `HIREDROP_RELOAD_EXT` (мост
  ping.js), потом перезагрузить вкладки дашборда. UI-кнопки через osascript флачат —
  надёжнее postMessage тем же сообщением, что шлёт кнопка.
- Токен Игоря = cookie `sb-…-auth-token.0/.1` (base64- префикс → JSON.access_token)
  из его же вкладки; профиль писать через `POST /profile` ПОЛНЫМ телом (частичное
  затирает базовые поля дефолтами).
